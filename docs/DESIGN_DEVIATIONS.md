# Proposed design deviations

All rows are **proposed**, not approved. The app applies these truthfulness and navigation corrections from the supplied project brief. Paul reviews them at Sprint 1. Any rejected row must be revisited before release.

| ID   | Screen / element              | Reference design                                       | Proposed implementation                                                                                                                                                              | Reason                                                   | Status   |
| ---- | ----------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- | -------- |
| F-01 | Source / certification claims | “Officine certifiée”, “officiel”, ONPC by default      | Show the real source and update date; use “officiel” only when the source is verified official.                                                                                      | Prevent unsupported medical claims.                      | Proposed |
| F-02 | Counts and pack sizes         | Fixed pharmacy, night, result, impact and size numbers | Compute from published data; remove user-impact/telemetry claims.                                                                                                                    | Avoid invented data.                                     | Proposed |
| F-03 | Report confirmation           | Fixed case reference and 2-hour promise                | Thank the user and show only the actual server reference; promise no review deadline.                                                                                                | No moderation SLA exists.                                | Proposed |
| F-04 | Navigation on search          | “Chercher” replaces Settings                           | Keep fixed Carte / Gardes / Favoris / Réglages tabs; search is a full-screen flow.                                                                                                   | Resolve inconsistent navigation.                         | Proposed |
| F-05 | Traffic controls/copy         | Traffic layer and traffic claims                       | Reuse map control slot for 2D/3D; label routes “Estimation hors trafic”; use off-route GPS state instead of unsupported traffic detection.                                           | No verified traffic feed.                                | Proposed |
| F-06 | Route subtitle                | Safety / sidewalk / zone assertions                    | Use a route-engine road name only when returned; otherwise omit the claim.                                                                                                           | No reliable safety/sidewalk data.                        | Proposed |
| F-07 | Insurance / services          | CNPS, payment, delivery, screening claims              | Show only when a source provides the value; remove CNPS until sourced.                                                                                                               | No confirmed source.                                     | Proposed |
